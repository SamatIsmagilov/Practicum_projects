# Анализ внутриигровых покупок в игре «Секреты Тёмнолесья» (SQL)

## Описание проекта

Данный проект представляет собой исследовательский анализ данных (EDA) и решение ad hoc-задачи для мобильной игры **«Секреты Тёмнолесья»**. 

**Цель исследования:** изучить влияние характеристик игроков и их игровых персонажей (расы) на покупку внутриигровой валюты «райские лепестки», а также оценить активность игроков при совершении покупок.

**Исследуемый набор данных:**
Работа велась с реляционной базой данных (схема `fantasy`), включающей таблицы:
* `users` — информация об игроках (флаг платящего игрока, ID расы).
* `race` — справочник рас.
* `events` — лог транзакций (стоимость покупки `amount`, код предмета).
* `items` — справочник предметов.

**Основные задачи исследования:**
1. **EDA:** Рассчитать долю платящих игроков (в целом и по расам), изучить статистику стоимости покупок (мин/макс/среднее/медиана/разброс), выявить аномальные нулевые покупки, найти самые популярные эпические предметы.
2. **Ad hoc-задача:** Проверить зависимость активности игроков (доля покупателей, среднее количество покупок, средний чек) от расы персонажа.

**Стек технологий:**
* **Язык запросов:** SQL (диалект PostgreSQL).
* **Инструменты:** 
  * Агрегатные функции и условная логика (`CASE WHEN`).
  * Обобщенные табличные выражения (CTE / `WITH`).
  * Оконные функции и перцентили (`PERCENTILE_DISC`).
  * Объединения таблиц (`LEFT JOIN`).

## Инструкция по развёртыванию и системные требования

**Системные требования:**
* Любая СУБД с поддержкой стандарта SQL и оконных функций (рекомендуется **PostgreSQL 12+**, так как синтаксис `::float` и `PERCENTILE_DISC` ориентирован на него).
* Клиент для работы с базой данных (DBeaver, DataGrip, pgAdmin и т.д.).

**Инструкция по запуску:**
1. Клонируйте репозиторий:
   `git clone https://github.com/ваш-логин/название-репозитория.git`
2. Разверните базу данных (необходимо восстановить дамп БД со схемой `fantasy` и таблицами `users`, `race`, `events`, `items`).
3. Откройте файл `Games.sql` в вашем SQL-клиенте.
4. Поочередно выполняйте запросы, чтобы получить статистику и аналитику.

## Выводы по результатам проекта

**1. Результаты EDA:**
* **Доля платящих:** Для всей игры доля платящих игроков составляет **17.7%**. Раса персонажа оказывает лишь незначительное влияние на этот показатель.
* **Стоимость покупок:** Всего совершено **1 307 678** покупок. Наблюдается сильный разрыв между средним значением и медианой (около 450.8), что указывает на асимметрию: небольшая группа игроков совершает очень дорогие покупки. Выявлено **907** аномальных нулевых покупок.
* **Популярные предметы:** Топ-3 эпических предмета — *Book of Legends* (76.9% продаж), *Bag of Holding* (20.8%) и *Necklace of Wisdom* (1%).

**2. Результаты ad hoc-задачи и рекомендации:**
* Доля игроков, совершающих покупки, практически одинакова у всех рас (60–63%), но среднее количество покупок на игрока сильно различается.
* **Раса Himat** лидирует по частоте покупок (покупают часто, но дешевле).
* **Раса Northman** лидирует по среднему чеку и выручке на игрока (покупают реже, но дороже).
* Доля платящих среди покупателей невысока (16–20%), основную массу покупок совершают неплатящие игроки. **Рекомендация:** разработать таргетированные акции для частых мелких покупок (Himat) и премиум-предложения (Northman).
