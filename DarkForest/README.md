# Предобработка и анализ исторических данных об играх (Python)

## Описание проекта

Данный проект посвящен подготовке исторических данных об играх к анализу для последующей публикации статьи о развитии игровой индустрии с 2000 по 2013 год. 

В рамках проекта необходимо было проверить корректность данных, очистить их, нормализовать, отфильтровать нужный временной период и категоризировать игры по оценкам пользователей и критиков.

**Исследуемый набор данных:**
Датасет `new_games.csv` содержит 16 956 строк и 11 столбцов с информацией о продажах игр в разных регионах (NA, EU, JP, Other), платформах, жанрах, годах выпуска, а также оценках критиков (от 0 до 100) и пользователей (от 0 до 10). 

**Основные задачи исследования:**
1. Загрузить данные и провести первичный анализ (типы данных, пропуски).
2. Привести названия столбцов к стилю `snake_case`.
3. Исправить некорректные типы данных (преобразовать строковые значения продаж и оценок в числовые).
4. Обработать пропущенные значения (заполнить или удалить в зависимости от контекста).
5. Нормализовать текстовые данные (привести к единому регистру) и удалить явные/неявные дубликаты.
6. Отфильтровать игры, выпущенные в период с 2000 по 2013 год включительно.
7. Категоризировать игры по оценкам (высокая, средняя, низкая) на основе шкал критиков и пользователей.
8. Выделить топ-7 платформ по количеству выпущенных игр за актуальный период.

**Стек технологий и библиотеки:**
* **Язык:** Python 3.9+
* **Библиотеки для обработки данных:** `pandas`, `numpy`
* **Среда разработки:** Jupyter Notebook

## Инструкция по развёртыванию и системные требования

**Системные требования:**
* Операционная система: Windows, macOS или Linux.
* Установленный Python версии 3.8 или выше.
* Jupyter Notebook или JupyterLab (либо среда разработки вроде VS Code / PyCharm с поддержкой `.ipynb`).

**Инструкция по запуску:**
1. Клонируйте репозиторий на локальный компьютер:
   `git clone https://github.com/ваш-логин/название-репозитория.git`
2. Перейдите в папку с проектом:
   `cd название-репозитория`
3. Создайте и активируйте виртуальное окружение (рекомендуется):
   `python -m venv venv`
   `source venv/bin/activate` (для Windows: `venv\Scripts\activate`)
4. Установите необходимые зависимости:
   `pip install pandas numpy jupyter`
5. Запустите Jupyter Notebook:
   `jupyter notebook`
6. Откройте файл ноутбука (`.ipynb`) и выполните все ячейки (Run All).

## Выводы по результатам проекта

В ходе предобработки данных были успешно решены все поставленные задачи:
* **Очистка данных:** Исправлены типы данных для столбцов продаж и оценок, обработаны пропуски (удалено 0.01% строк, заполнены пропуски в году выпуска и продажах), удалено 241 явных дубликатов и устранены неявные дубликаты в текстовых полях (жанры, платформы).
* **Итоговый размер после очистки:** 16 713 строк (потеря данных составила всего 1.43%).
* **Фильтрация:** Для дальнейшего анализа оставлен период с 2000 по 2013 год, что составило 13 021 строка.
* **Категоризация оценок:** 
  * По оценкам пользователей: «высокая» (2 328 игр), «средняя» (4 159 игр), «низкая» (119 игр).
  * По оценкам критиков: «высокая» (1 724 игры), «средняя» (5 536 игр), «низкая» (58 игр).
* **Топ-7 платформ** за актуальный период по количеству игр: **PS2** (2 161), **DS** (2 150), **WII** (1 309), **PSP** (1 196), **X360** (1 151), **PS3** (1 112) и **XB** (824). 

Полученный очищенный датафрейм готов к дальнейшему исследовательскому анализу (EDA) и написанию статьи об индустрии игр.
