# Секреты Темнолесья: Подготовка данных об играх (2000–2013)

## Описание проекта

Данный проект выполнен в рамках задачи для команды игры «Секреты Темнолесья». Цель исследования — подготовить исторические данные об играх для последующего написания статьи о развитии игровой индустрии в начале XXI века. 

В ходе работы были изучены данные об играх, выпущенных на различных платформах, их продажах в разных регионах, а также пользовательские и экспертные оценки. Акцент в подготовке сделан на очистку данных, фильтрацию нужного временного промежутка (с 2000 по 2013 год) и категоризацию игр по уровню оценок.

### Основные задачи:
1. Загрузить и изучить исходные данные.
2. Провести предобработку: переименовать столбцы (snake_case), исправить типы данных, обработать пропуски и дубликаты.
3. Отфильтровать данные за период с 2000 по 2013 год включительно.
4. Категоризовать игры по оценкам пользователей и критиков (высокая, средняя, низкая).
5. Выделить топ-7 платформ по количеству выпущенных игр за требуемый период.

### Стек технологий и библиотеки
* **Язык программирования:** Python 3.9+
* **Библиотеки для анализа данных:** 
  * `pandas` (загрузка, очистка, трансформация и агрегация данных)
  * `numpy` (работа с массивами и пропущенными значениями)

## Данные и предобработка

Исходный датасет `new_games.csv` содержит **16 956 строк** и **11 столбцов** (`Name`, `Platform`, `Year of Release`, `Genre`, `NA sales`, `EU sales`, `JP sales`, `Other sales`, `Critic Score`, `User Score`, `Rating`).

В ходе предобработки были выполнены следующие шаги:
* **Переименование:** названия столбцов приведены к стилю `snake_case`.
* **Типы данных:** столбцы продаж (`eu_sales`, `jp_sales`) и пользовательских оценок (`user_score`) были преобразованы из строкового типа в числовой (`float64`) с помощью `pd.to_numeric(errors='coerce')`.
* **Пропуски:** 
  * Удалены единичные пропуски в названиях и жанрах (2 строки).
  * Пропуски в продажах заполнены средними значениями по группе (платформа + год).
  * Пропуски в годе выпуска заполнены медианой по платформе.
  * Пропуски в оценках и рейтинге ESRB (около 40-50%) оставлены как есть, чтобы не искажать выборку.
* **Неявные дубликаты:** платформы приведены к верхнему регистру, жанры — к нижнему, рейтинги — к верхнему.
* **Явные дубликаты:** удалено 241 полных дубликатов строк (1.42% данных).
* **Фильтрация:** итоговый датафрейм (`df_actual`) содержит **13 021 строку** за период с 2000 по 2013 год.

## Основные выводы по результатам подготовки данных

1. **Категоризация оценок:**
   * По оценкам пользователей (от 0 до 10): большинство игр получили «среднюю» оценку (4 159 игр), «высокую» — 2 328 игр, «низкую» — всего 119 игр.
   * По оценкам критиков (от 0 до 100): также преобладает «средняя» категория (5 536 игр), «высокая» — 1 724 игры, «низкая» — 58 игр.
2. **Топ-7 платформ (2000–2013 гг.):**
   За исследуемый период лидерами по количеству выпущенных игр стали:
   1. **PS2** — 2 161 игра
   2. **DS** — 2 150 игр
   3. **WII** — 1 309 игр
   4. **PSP** — 1 196 игр
   5. **X360** — 1 151 игра
   6. **PS3** — 1 112 игр
   7. **XB** — 824 игры

Данные успешно очищены, категоризованы и готовы к дальнейшему исследовательскому анализу (EDA) и визуализации для написания статьи.
