# Анализ результатов A/B-тестирования и проверка статистических гипотез

## Описание проекта

Данный проект состоит из двух частей и посвящен статистическому анализу данных и оценке результатов A/B-тестирования для интернет-магазина **BitMotion Kit**. 

В первой части проекта проверялась гипотеза о различии пользовательской активности (времени чтения и прослушивания) между пользователями из Москвы и Санкт-Петербурга.
Во второй части оценивалась корректность проведения A/B-теста нового интерфейса сайта и его влияние на ключевую бизнес-метрику — конверсию пользователей в покупатели.

**Исследуемые наборы данных:**
1. `yandex_knigi_data.csv` — данные о городах пользователей и их активности в часах (включает аномальные выбросы и дубликаты).
2. `ab_test_participants.csv` — данные об участниках A/B-тестов (содержит информацию о группах, устройствах и пересечениях между тестами).
3. `ab_test_events.zip` — лог событий пользователей за 2020 год (регистрации, просмотры страниц, покупки).

**Цели исследования:**
* Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят в среднем больше времени в приложении, чем пользователи из Москвы.
* Оценить корректность проведения A/B-теста (проверка равномерности распределения, отсутствия пересечений с другими тестами, соответствия временному горизонту).
* Определить, приводит ли упрощение интерфейса (тестовая группа B) к статистически значимому росту конверсии в покупку по сравнению с контрольной группой A.
* Сравнить фактический прирост конверсии с ожидаемым эффектом (+3 п.п.) и сформулировать рекомендации для бизнеса.

**Основные этапы работы:**
1. Загрузка данных и проверка их целостности (обработка пропусков и дубликатов).
2. Выделение целевой аудитории, очистка от пересечений с конкурирующими тестами (исключено 887 пользователей).
3. Расчет «лайфтайма» и фильтрация событий за первые 7 дней с момента регистрации.
4. Оценка достаточности размера выборки (расчет требуемого размера выборки для мощности 80% и достоверности 95%).
5. Расчет метрики конверсии для групп А и В.
6. Проверка статистических гипотез (t-тест Уэлча для средних значений и односторонний Z-тест для двух пропорций).

**Использованные библиотеки:**
* `pandas` — для загрузки, очистки, фильтрации и агрегации данных.
* `numpy` — для математических вычислений и работы с массивами.
* `matplotlib`, `seaborn` — для визуализации распределений данных (гистограммы).
* `scipy.stats` — для расчета t-статистики (тест Уэлча) и параметров распределения.
* `statsmodels.stats.proportion` — для проведения Z-теста пропорций.

## Выводы по результатам проекта

**1. По первой части (Активность в Москве и СПб):**
* Распределение времени активности имеет сильную правостороннюю асимметрию и выбросы (небольшая группа «суперактивных» пользователей).
* Среднее время в Санкт-Петербурге (11.26 ч.) немного выше, чем в Москве (10.88 ч.).
* Однако односторонний t-тест Уэлча показал **p-value = 0.34** (что больше 0.05). У нас нет оснований отвергнуть нулевую гипотезу: разница в активности между городами **статистически незначима** и, вероятно, обусловлена случайностью выборки и высокой дисперсией данных.

**2. По второй части (A/B-тест интерфейса BitMotion Kit):**
* В ходе проверки данных были обнаружены пересечения пользователей с другим тестом (887 человек), которые были удалены для чистоты эксперимента. Выборка после очистки составила 9963 пользователя, что достаточно для выявления заданного эффекта.
* Конверсия в контрольной группе (A) составила **27.81%**, в тестовой группе (B) — **29.54%**. Абсолютный прирост — **+1.73 п.п.**
* Односторонний Z-тест для двух пропорций показал **p-value = 0.028** (< 0.05). Различие **статистически значимо**. Новый интерфейс действительно повышает конверсию.
* **Итоговая рекомендация:** Несмотря на статистическую значимость, фактический прирост (+1.73 п.п.) оказался ниже целевого показателя, заложенного в техническом задании (+3 п.п.). В связи с этим **не рекомендуется** внедрять новый интерфейс в текущем виде. Команде дизайнеров и разработчиков следует продолжить оптимизацию интерфейса для достижения ожидаемого бизнес-эффекта.
