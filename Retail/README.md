# Анализ результатов A/B-тестирования интернет-магазина (Python)

## Описание проекта

Данный проект посвящен статистическому анализу данных и оценке результатов A/B-тестирования для интернет-магазина **BitMotion Kit**. Проект состоит из двух частей.

**Исследуемые наборы данных:**
1. `yandex_knigi_data.csv` — данные о городах пользователей и их активности (в часах).
2. `ab_test_participants.csv` — данные об участниках A/B-тестов (группы, устройства).
3. `ab_test_events.zip` — лог событий пользователей за 2020 год.

**Цели исследования:**
* Проверить гипотезу о различии пользовательской активности между Москвой и Санкт-Петербургом.
* Оценить корректность проведения A/B-теста нового интерфейса (проверка пересечений, равномерности).
* Определить, приводит ли упрощение интерфейса (группа B) к статистически значимому росту конверсии в покупку по сравнению с контрольной группой (A), и сравнить результат с ожидаемым эффектом (+3 п.п.).

**Стек технологий и библиотеки:**
* **Язык:** Python 3.9+
* **Библиотеки для анализа данных:** `pandas`, `numpy`
* **Библиотеки для статистики:** `scipy.stats` (t-тест Уэлча), `statsmodels.stats.proportion` (Z-тест для пропорций)
* **Визуализация:** `matplotlib`, `seaborn`

## Теги

`python` `data-analysis` `ab-testing` `statistics` `hypothesis-testing` `pandas` `scipy` `statsmodels` `data-visualization`

## Выводы по результатам проекта

**1. Активность в Москве и СПб:**
* Среднее время в Санкт-Петербурге (11.26 ч.) немного выше, чем в Москве (10.88 ч.).
* Однако односторонний t-тест Уэлча показал **p-value = 0.34** (> 0.05). Разница в активности между городами **статистически незначима** и, вероятно, обусловлена высокой дисперсией данных.

**2. Результаты A/B-теста интерфейса:**
* После очистки данных от пересечений с другими тестами конверсия в контрольной группе (A) составила **27.81%**, в тестовой (B) — **29.54%**. Прирост — **+1.73 п.п.**
* Односторонний Z-тест показал **p-value = 0.028** (< 0.05). Новый интерфейс **статистически значимо** повышает конверсию.
* **Итоговая рекомендация:** Фактический прирост (+1.73 п.п.) оказался ниже целевого показателя ТЗ (+3 п.п.). В связи с этим **не рекомендуется** внедрять новый интерфейс в текущем виде; требуется дальнейшая оптимизация.

## Инструкция по развёртыванию и системные требования

**Системные требования:**
* Операционная система: Windows, macOS или Linux.
* Установленный Python версии 3.8 или выше.
* Jupyter Notebook или JupyterLab (либо среда разработки вроде VS Code / PyCharm с поддержкой `.ipynb`).

**Инструкция по запуску:**
1. Клонируйте репозиторий на локальный компьютер:
   `git clone https://github.com/ваш-логин/название-репозитория.git`
2. Перейдите в папку с проектом:
   `cd название-репозитория`
3. Создайте и активируйте виртуальное окружение (рекомендуется):
   `python -m venv venv`
   `source venv/bin/activate` (для Windows: `venv\Scripts\activate`)
4. Установите необходимые зависимости:
   `pip install pandas numpy scipy statsmodels matplotlib seaborn jupyter`
5. Запустите Jupyter Notebook:
   `jupyter notebook`
6. Откройте файл с расширением `.ipynb` и выполните все ячейки (Run All).
