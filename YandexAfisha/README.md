# Исследовательский анализ данных сервиса Яндекс Афиша

## Описание проекта

**Назначение:**
Продуктовая команда сервиса Яндекс Афиша заметила изменение пользовательского спроса осенью 2024 года. Целью данного проекта является проведение исследовательского анализа данных (EDA) для выявления причин этих изменений: связаны ли они с сезонным фактором, сменой предпочтений аудитории или ростом популярности определенных событий. Также в рамках проекта проверяются гипотезы о различиях в поведении пользователей мобильных и стационарных устройств.

**Исследуемый набор данных:**
Анализ проводился на основе трех датасетов за период с 1 июня по 31 октября 2024 года:
*   `final_tickets_orders_df.csv` — информация о заказах билетов (пользователи, устройства, выручка, валюта).
*   `final_tickets_events_df.csv` — информация о мероприятиях (типы событий, регионы, площадки).
*   `final_tickets_tenge_df.csv` — ежедневный курс казахстанского тенге к российскому рублю.

**Основные пункты исследования:**
1.  **Предобработка данных:** очистка от дубликатов, обработка выбросов и приведение выручки к единой валюте (рублям) через `revenue_rub`.
2.  **Исследовательский анализ:** изучение динамики заказов, сезонных изменений в предпочтениях (театр, концерты, спорт), анализ активности по дням недели, а также выявление регионов и партнеров-лидеров.
3.  **Статистический анализ:** проверка гипотез о количестве заказов и времени между покупками для пользователей mobile и desktop.

**Стек технологий и библиотеки:**
*   **Язык:** Python 3.9
*   **Библиотеки для работы с данными:** `pandas`, `numpy`
*   **Библиотеки для визуализации:** `matplotlib`, `seaborn`
*   **Библиотеки для статистики:** `scipy.stats`

## Выводы

В ходе исследования были получены следующие ключевые результаты:

1.  **Сезонность и рост:** Осенью наблюдается устойчивый рост количества заказов. Однако средний чек снижается. Рост происходит за счет массовых и более доступных категорий (театр, спорт), а не за счет премиальных событий.
2.  **Поведение пользователей:**
    *   **Mobile vs Desktop:** Пользователи мобильных устройств совершают в среднем на **34.3%** больше заказов (статистически значимо, p-value < 0.05). Однако медианное количество заказов у них равно, что говорит о наличии «гипер-активных» пользователей на мобильных устройствах.
    *   **Время между заказами:** Значимых различий во времени между покупками (в среднем 12 дней) между пользователями мобильных и стационарных устройств не выявлено (p-value = 0.188).
    *   **Недельная цикличность:** В будни совершается больше заказов (оптовые покупки), а в выходные выше DAU (уникальные пользователи) и средний чек.
3.  **Концентрация рынка:**
    *   **Регионы:** Топ-3 региона (Каменевский, Североярская, Широковская области) генерируют **~52%** всех заказов.
    *   **Партнеры:** Топ-3 билетных оператора («Билеты без проблем», «Мой билет», «Облачко») обеспечивают **43.5%** всей выручки сервиса.

## Инструкция по развёртыванию и системные требования

**Системные требования:**
*   Операционная система: Windows, macOS или Linux.
*   Python версии 3.9 или выше.
*   Установленный менеджер пакетов `pip`.
*   Рекомендуемый объем оперативной памяти: от 4 ГБ.

**Инструкция по запуску:**
1.  Клонируйте репозиторий с проектом на локальную машину:
    ```bash
    git clone <URL_вашего_репозитория>
    cd <название_папки_проекта>

2. Установите необходимые библиотеки, выполнив в терминале команду:
    pip install pandas numpy matplotlib seaborn scipy

3. Убедитесь, что файлы с данными (final_tickets_orders_df.csv, final_tickets_events_df.csv, final_tickets_tenge_df.csv) находятся в папке /datasets/ относительно корня проекта.

4. Запустите Jupyter Notebook или JupyterLab:
    jupyter notebook

5. Откройте файл с расширением .ipynb и выполните все ячейки кода последовательно (меню Cell -> Run All).
