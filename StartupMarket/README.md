# Исследование рынка венчурных инвестиций и стартапов

## Описание проекта

**Назначение:**
Данный проект представляет собой комплексный анализ исторических данных о венчурных инвестициях. Цель исследования — выявить закономерности финансирования стартапов, оценить перспективы выхода на рынок и сформулировать инвестиционные рекомендации для гипотетического инвестора в 2015 году.

**Исследуемый набор данных:**
В работе используются два датасета:
1. `cb_investments.csv` — основная база данных стартапов, содержащая информацию о компаниях, категориях рынка, объемах и типах привлеченных инвестиций, датах раундов и статусах.
2. `cb_returns.csv` — дополнительная статистика по возвратам средств инвесторам по годам и типам финансирования.

**Основные пункты исследования:**
* **Предобработка данных:** Очистка от дубликатов, обработка пропусков, приведение типов данных (включая `funding_total_usd` и даты).
* **Инжиниринг признаков:** Группировка компаний по срокам финансирования, классификация рыночных сегментов (массовые, средние, нишевые), расчет среднего размера раунда.
* **Анализ аномалий:** Выявление выбросов (IQR метод) внутри каждого рыночного сегмента и их исключение.
* **Динамический анализ:** Исследование изменения объемов инвестиций, количества сделок по годам и анализ динамики нормированных возвратов.
* **Формулировка выводов:** Определение перспективных отраслей и типов финансирования.

**Стек технологий:**
Для выполнения анализа использовались следующие библиотеки Python:
* **`pandas`** — загрузка, очистка и трансформация данных.
* **`numpy`** — математические вычисления.
* **`matplotlib`** и **`seaborn`** — визуализация данных (построение графиков динамики, распределений и выбросов).

## Выводы по результатам проекта

В ходе анализа были сделаны следующие ключевые выводы:

1. **Структура финансирования:** Большинство компаний (около 59%) получают финансирование только один раз. Однако компании, проходящие несколько раундов (группа «Более года»), аккумулируют более 61% всех инвестиций.
2. **Динамика рынка:** 2014 год является пиковым по количеству активных компаний и сделок, хотя медианный размер одного раунда к этому времени снизился по сравнению с началом 2000-х.
3. **Сегменты рынка:** Рынок поляризован. Существует 49 массовых сегментов (например, Software, Biotechnology) и огромное количество нишевых (более 289).
4. **Растущие отрасли (на 2014 год):** Наиболее быстрый и уверенный рост суммарного финансирования показали сегменты **Medical**, **Apps** и **Startups**.
5. **Возврат инвестиций:** Венчурное финансирование (`venture`) доминирует как по объему вложений, так и по объему возвратов. В 2014 году наблюдается синхронный резкий рост нормированных возвратов по всем основным типам финансирования, что сигнализирует о высокой потенциальной доходности.
6. **Рекомендация (сценарий 2015 года):** Целесообразно инвестировать в массовые сегменты **Medical**, **Apps** и **Startups**, используя **венчурное финансирование** (`venture`) как основной инструмент для получения максимальной отдачи.

## Инструкция по развёртыванию и системные требования

**Системные требования:**
* Python версии 3.8 или выше.
* Установленный Jupyter Notebook или Google Colab.

**Необходимые библиотеки:**
Установить зависимости можно с помощью команды:
```bash
pip install pandas numpy matplotlib seaborn
```

**Запуск проекта:**
1. Скачайте файл ноутбука `StartupMarket.ipynb`.
2. Запустите Jupyter Notebook:
    ```bash
    jupyter notebook StartupMarket.ipynb
    ```
3. Выполните все ячейки кода последовательно (`Run All` или `Cell -> Run All`).

**Данные:**
Датасеты загружаются автоматически по ссылкам из облачного хранилища внутри кода ноутбука, поэтому предварительная загрузка файлов не требуется.
