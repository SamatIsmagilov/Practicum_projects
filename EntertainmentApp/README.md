# Разработка A/B-тестирования и анализ результатов

## Описание проекта

**Назначение:**
Данный проект посвящен проектированию, проведению и анализу A/B-теста для приложения с «бесконечной» лентой коротких видео. Компания разработала новый ML-алгоритм ранжирования контента, который учитывает персональные интересы пользователя (прошлые лайки и длительность просмотра), чтобы увеличить глубину просмотра (просмотр более 80% видео). Цель исследования — проверить гипотезу о том, что новый алгоритм статистически значимо повышает вовлеченность пользователей (метрику `page_counter`), и вынести вердикт о целесообразности его внедрения для всех пользователей.

**Исследуемый набор данных:**
В работе используются три таблицы с данными о сессиях пользователей (идентификаторы, даты, регион, устройство, количество просмотренных страниц и т.д.):
1.  `sessions_project_history.csv` — исторические данные для планирования теста (2025-08-11 по 2025-09-23).
2.  `sessions_project_test_part.csv` — данные за первый день A/B-теста для проверки корректности сплитования (2025-10-14).
3.  `sessions_project_test.csv` — полные данные за весь период A/B-теста для анализа результатов (2025-10-14 по 2025-11-02).

**Основные пункты исследования:**
*   **EDA и предобработка:** Изучение исторических данных, анализ динамики регистраций и распределения просмотров страниц.
*   **Планирование теста:** Определение целевой метрики (доля «успешных» сессий с 4+ просмотрами), расчет необходимого размера выборки и длительности эксперимента на основе текущего трафика.
*   **Мониторинг корректности:** Проверка равномерности распределения пользователей по группам A и B, а также отсутствия пересечений и дисбаланса по устройствам и регионам в первый день теста.
*   **Статистический анализ:** Сравнение доли успешных сессий между группами с помощью Z-теста, расчет p-value и формулировка итогового вердикта.

**Стек технологий:**
*   **`pandas`** — обработка и анализ данных.
*   **`numpy`** — математические вычисления.
*   **`matplotlib`** — визуализация данных.
*   **`statsmodels`** — статистические тесты (расчет размера выборки, Z-тест для пропорций).

## Выводы по результатам проекта

В ходе анализа были сделаны следующие ключевые выводы:

1.  **Корректность сплитования:** A/B-тест был запущен корректно. В первый день теста разница в размерах выборок составила всего 0.74% (1477 пользователей в группе A и 1466 в группе B). Пересечений пользователей между группами нет, а распределение по устройствам и регионам равномерное.
2.  **Влияние на метрику:** Доля успешных первых сессий (просмотр 4+ страниц) в контрольной группе A составила **31.57%**, а в тестовой группе B — **31.47%**. Разница составила -0.11 процентных пункта.
3.  **Статистическая значимость:** По результатам Z-теста для двух долей значение **p-value составило 0.8433**. Это значительно выше принятого уровня значимости (0.05). Следовательно, разница между группами является статистически незначимой.
4.  **Вердикт:** Новый алгоритм рекомендаций **не показал** статистически значимого улучшения ключевой метрики. Более того, показатели тестовой группы оказались незначительно хуже контрольной. Внедрять модель для всех пользователей в текущем виде **не рекомендуется**. Также стоит отметить, что фактическая длительность теста была меньше расчетной из-за более низкого, чем ожидалось, трафика.

## Инструкция по развёртыванию и системные требования

**Системные требования:**
*   Python версии 3.8 или выше.
*   Установленный Jupyter Notebook или Google Colab.

**Необходимые библиотеки:**
Установить зависимости можно с помощью команды:
```bash
pip install pandas numpy matplotlib statsmodels
```

**Запуск проекта:**
1.  Скачайте файл ноутбука `EntertainmentApp.ipynb`.
2.  Запустите Jupyter Notebook:
    ```bash
    jupyter notebook EntertainmentApp.ipynb
    ```
3.  Выполните все ячейки кода последовательно (`Run All` или `Cell -> Run All`).

**Данные:**
В ноутбуке используются пути к файлам `/datasets/sessions_project_*.csv`. Если вы запускаете проект локально, убедитесь, что файлы данных скачаны и находятся в той же директории, что и ноутбук, или измените пути в функции `pd.read_csv()` на локальные.
