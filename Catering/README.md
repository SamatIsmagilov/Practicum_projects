# Исследование рынка общественного питания Москвы

## Описание проекта

Данный проект представляет собой исследовательский анализ рынка общественного питания Москвы на основе данных сервисов Яндекс Карты и Яндекс Бизнес за лето 2022 года. Заказчиком выступает инвестиционный фонд, планирующий открыть новое заведение (кафе, ресторан или бар) и нуждающийся в аналитике для выбора оптимального места, формата и ценовой политики.

**Исследуемый набор данных:**
Проект использует два датасета, объединяемых по `id`:
1.  `rest_info.csv` — базовая информация о заведениях (название, адрес, административный район, категория, часы работы, рейтинг, статус сетевого заведения, количество посадочных мест).
2.  `rest_price.csv` — информация о ценах (категория цен, средний чек, медианное значение среднего чека и цены чашки капучино).

**Цели исследования:**
*   Изучить структуру рынка общественного питания Москвы (категории, распределение по районам, сетевые/несетевые заведения).
*   Проанализировать посадочные места и выявить аномалии.
*   Изучить рейтинги заведений, их зависимость от различных факторов (категория, район, цена) с помощью корреляционного анализа.
*   Определить топ-15 популярных сетей.
*   Выявить зависимость среднего чека от удаленности от центра города.
*   Сформулировать итоговые рекомендации для инвестора.

**Стек технологий и библиотеки:**
*   **Язык:** Python 3.9+
*   **Библиотеки для анализа данных:** `pandas`, `numpy`
*   **Библиотеки для визуализации:** `matplotlib`, `seaborn`
*   **Библиотеки для статистики:** `phik` (для расчета матрицы корреляции Phi-K с категориальными данными)
*   **Среда разработки:** Jupyter Notebook

## Выводы, к которым пришли по результатам проекта

*   **Структура рынка:** Рынок сильно смещен в сторону **кафе, ресторанов и кофеен**. Наблюдается сильная географическая концентрация: **Центральный административный округ (ЦАО)** — абсолютный лидер по количеству заведений (почти 27%), где, в отличие от остального города, преобладают рестораны и бары.
*   **Сети:** Большинство заведений (61.9%) — несетевые. Сети доминируют в нишах булочных, пиццерий и кофеен. Лидер по количеству точек — сеть **«Шоколадница»**, но по качеству (среднему рейтингу) лидируют небольшие сети **«Буханка»** и **«Кулинарная лавка братьев Караваевых»**.
*   **Вместимость:** Медианное количество посадочных мест по всем заведениям (без учета нулей) — **78**. Самые крупные форматы — рестораны (медиана 90 мест) и бары (84 места). В данных присутствуют заведения-гиганты (выбросы) до 1288 мест.
*   **Рейтинги и цены:** Средний рейтинг по городу высокий — **4.23**. Корреляционный анализ показал, что рейтинг слабо зависит от формальных признаков. Самая сильная связь — с **ценовой категорией** (коэффициент Phi-K = 0.22). Заведения с высокими ценами имеют средний рейтинг 4.44, а с низкими — 4.17.
*   **География цен:** Удаленность от центра напрямую влияет на чек. Медианный чек в ЦАО и на Западе составляет **1000 ₽**, в то время как в остальных округах — **600 ₽** (разница 400 ₽). Самый дешевый округ — Юго-Восточный (450 ₽).

## Инструкция по развёртыванию и системные требования

**Системные требования:**
*   Операционная система: Windows, macOS или Linux.
*   Установленный Python версии 3.8 или выше.
*   Jupyter Notebook или JupyterLab (либо среда разработки вроде VS Code / PyCharm с поддержкой `.ipynb`).

**Инструкция по запуску:**
1. Клонируйте репозиторий на локальный компьютер:
   `git clone https://github.com/ваш-логин/название-репозитория.git`
2. Перейдите в папку с проектом:
   `cd название-репозитория`
3. Создайте и активируйте виртуальное окружение (рекомендуется):
   `python -m venv venv`
   `source venv/bin/activate` (для Windows: `venv\Scripts\activate`)
4. Установите необходимые зависимости:
   `pip install pandas numpy matplotlib seaborn phik jupyter`
5. Запустите Jupyter Notebook:
   `jupyter notebook`
6. Откройте файл ноутбука (`.ipynb`) и выполните все ячейки (Run All).
